# 🏭 FICSIT Architect & Production Calculator (Satisfactory 1.0)

**FICSIT Architect** — это высокопроизводительная веб-САПР и комплексная система управления производственной логистикой, спроектированная специально для релизной версии **Satisfactory 1.0** в аутентичном индустриальном стиле SCIM (*Satisfactory Calculator Interactive Map*).

В отличие от стандартных табличных калькуляторов, FICSIT Architect объединяет **симплекс-оптимизацию линейного программирования**, **физическую развертку цехов поштучно до каждого станка**, **сквозной расчет межзаводского транзита между 11 этапами кампании**, **трекинг Космического Лифта (5 фаз)** и **систему чеклиста постройки с локальной фиксацией в IndexedDB**.

🌐 **[Открыть Live Demo онлайн](https://ziyadabek.github.io/ficsit-town-manager/)**

## ⚡ Ключевые модули и архитектура

### 📊 1. Планировщик Производства (Production Planner)
* **Simplex LP-Солвер (`javascript-lp-solver`):** Мгновенный расчет глобального производственного оптимума с минимизацией сырья, энергопотребления или числа станков.
* **Альтернативные чертежи:** Полная поддержка всех 100+ альтернативных рецептов Satisfactory 1.0 (включая рецепты конвертера материи и квантового кодера).
* **VIP Hydro-Junction (Защита от гидролока):** Автоматическая вставка контуров приоритета вторичной воды (*VIP Junction*) для алюминиевых заводов и переработки отходов, исключающая завоздушивание и остановку труб.
* **Ограничения оборудования:** Настройка чистоты жил (бедные, обычные, чистые), лимитов конвейеров (Mk.1 – Mk.6 до 1200 шт/мин), труб (Mk.1 / Mk.2 до 600 м³/мин), сомерслупов (Петлевиков $\times 2$) и энергомодулей разгона.

### 🏭 2. Модуль «Реалистичный цех» (SCIM Micro Layout)
* **Поштучная развертка станков:** Переключение из абстрактного узла (например, `10.4 плавильни`) в физическую 2D-схему цеха: 10 станков на 100% мощности + 1 станок с точной настройкой тактовой частоты (40%).
* **Балансированные сплиттерные и мерджерные деревья:** Движок `realisticGraphEngine.js` синтезирует каскадные коллекторы раздачи и сбора с соблюдением аппаратного лимита 3 портов на разветвитель/соединитель.
* **Умный сброс видов:** При переключении между этапами система автоматически открывает компактный режим для мгновенного отклика (0 мс), сохраняя детальный вид для закрепленных этапов.
* **Смена проекции:** Мгновенный поворот графа слева направо (➡️ `LR`) или сверху вниз (⬇️ `TB`).

### 🗺️ 3. Сквозная кампания: 11 индустриальных комплексов
Система включает готовую математически выверенную кампанию полного прохождения Satisfactory 1.0:
1. **ЭТАП 1:** Бетонный хаб по World Grid (540 шт/мин).
2. **ЭТАП 2:** Угольная ТЭС (+4800 МВт, 64 генератора).
3. **ЭТАП 3:** Тяжелая металлургия (Трубы, балки, стальные пластины).
4. **ЭТАП 4:** Сборочно-метизный хаб (Фазы 1–2 Лифта, винты, умная обшивка).
5. **ЭТАП 5:** Топливный энергокомплекс и полимеры (+6000 МВт, пластик, кокс).
6. **ЭТАП 6:** Тяжелое машиностроение (Тяжелые каркасы, моторы, Фаза 3).
7. **ЭТАП 7:** Электроника и суперкомпьютеры (Платы, кабели, кремний).
8. **ЭТАП 8:** Алюминиевый завод и системы охлаждения (с VIP-гидроконтуром).
9. **ЭТАП 9:** Атомный технопарк (+20 000 МВт, 8 реакторов, обращение с отходами).
10. **ЭТАП 10:** Верфь Космического Лифта (Фаза 4: Ядерная паста, Магнитные генераторы, Ракеты).
11. **ЭТАП 11:** Квантовая верфь (Фаза 5 Лифта: Варп-двигатели, Скафандры, Серверы ИИ).

### 🚚 4. Движок сквозного транзита (Dynamic Multi-Stage Transit)
* **Межзаводская логистика:** Расчет потоков ресурсов между удаленными этапами в реальном времени (`campaignTransitEngine.js`).
* **Расчет транспорта:** Автоматическое определение требуемого подвижного состава (тракторы с 25 слотами, цистерны 1600 м³, грузовые вагоны 32 слота, радиационные составы) и частоты рейсов/мин.
* **Пропорциональное деление пула:** Равномерное взвешенное распределение ресурсов между параллельными цехами при дефиците, исключающее «голодание» зависимых производств.

### 🚀 5. Орбитальный Космический Лифт: Проект «Сборка»
* Интерактивная панель мониторинга всех **5 Фаз Космического Лифта** (включая финальную квантовую Фазу 5 релиза 1.0).
* Быстрый переход к этапу-поставщику конкретной детали в один клик.
* Индикаторы прогресса и расчет чистого темпа сдачи компонентов.

### 🔀 6. Верстак Балансировщиков (Conveyor Balancers)
* Полный интерактивный каталог компактных топологий конвейерных балансировщиков (от `1:2`, `1:3`, `1:4` до `6:6` и `8:8`).
* Плавные изогнутые дуги Безье, цветовое кодирование потоков и 3D-модели узлов.

### ✅ 7. Инженерный чеклист постройки и фиксация этапов
* **Чеклист станков:** Отметка построенных станков прямо на чертеже в игре со светодиодным индикатором готовности (`🟢 Построено X/Y`).
* **Монолитный сегментный тулбар:** Единая промышленная капсула SCADA со счетчиком, быстрыми действиями (`✓ Все` / `↺ Сбросить`) и кнопкой фиксации цеха.
* **Заморозка цехов (Freeze Stage):** Закрепление построенных комплексов защищает их от случайного пересчета и гарантирует стабильную подачу полуфабрикатов на старшие этапы.

### 💾 8. Постоянное хранилище и Векторный Экспорт
* **W3C IndexedDB API:** Безопасное сохранение состояния сотен станков без риска `QuotaExceededError` (с автомиграцией из `localStorage`).
* **Резервные копии:** Экспорт и импорт полной базы цехов в файл `.json` через экономичные `Blob`-объекты.
* **Векторный SVG Blueprint:** Экспорт схемы в чистый векторный `.svg` с бесконечным зумом и высоким разрешением для печати или просмотра на втором мониторе.

## 🚀 Быстрый старт

### Требования
* **Node.js** версии 18+ (рекомендуется 20 LTS)
* Менеджер пакетов **npm**, **pnpm** или **yarn**

### Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/ziyadabek/ficsit-town-manager.git
   cd ficsit-town-manager
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите dev-сервер:
   ```bash
   npm run dev
   ```
   Приложение откроется по адресу `http://localhost:5173`.

4. Запуск тестов:
   ```bash
   npm test
   ```

5. Сборка продакшен-бандла:
   ```bash
   npm run build
   ```
